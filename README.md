## 🎮 Presentation Controls & Navigation

The bottom slide bar has been completely removed to keep your presentation clean and distraction-free on the projector. You can drive the presentation entirely using:

| Key / Action | What It Does |
| :--- | :--- |
| **`→` (Right Arrow)** or **`Space`** or **Click** | **Advances smoothly to the next slide** |
| **`←` (Left Arrow)** | **Steps back to the previous slide** |
| **`1`** | Jumps directly to **Speaker 1: Kiran** (1978 Delhi Tornado) |
| **`2`** | Jumps directly to **Speaker 2: Suriya** (The Unthinkable) |
| **`3`** | Jumps directly to **Speaker 3: Hari** (Science vs Culture) |
| **`4`** | Jumps directly to **Speaker 4: Yogesh** (Viksit Bharat 2047) |
| **`5`** | Jumps directly to **Speaker 5: Pradeep** (Global SDGs 11 & 13) |
| **`0`** or **`H`** | Returns to the Title / Cover slide |
| **`P`** | Toggles the slide-out **Speaker Cue Card** (talking points & time target) |
| **`F`** | Toggles **Fullscreen mode** for presentation |
| **`M`** | Toggles ambient sound effect |
| **`Esc`** | Closes any open notes or Q&A modal |

## ☀️ Projector Theme Highlights

* **Parchment Ivory Canvas (`#fcfbf7`)**: Prevents washed-out projection contrast common with dark themes in lit classrooms.
* **Deep Charcoal Typography (`#0f172a` & `#334155`)**: Maximizes readability from the back row of an auditorium.
* **Warm Terracotta & Emerald Accents (`#c2410c` & `#047857`)**: Rich editorial accents matching UN SDGs and Indian resilience strategies.
* **Discreet Top Counter**: High-contrast `01 / 09` indicator in the header keeps you oriented without cluttering the screen.
